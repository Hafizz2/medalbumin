MEDNEXUS — Connect Knowledge. Master Medicine.
MEDICAL EXAM APP · UI DESIGN
Mobile app (26 screens) + Admin panel (11 screens)

HOW TO VIEW
1. Unzip the folder (do not open files from inside the zip).
2. Open index.html in Chrome, Edge or Firefox.
   It shows every screen as a gallery. Click a screen to open it full size.
3. Each screen is clickable: tabs, buttons, toggles and links to other
   screens work, so you can walk through the app like a prototype.
   Start with screens/Main.dc.html for the mobile flow, or
   screens/AdminDashboard.dc.html for the admin panel.

Fonts load from Google Fonts, so an internet connection makes it look
exactly as designed. Offline it falls back to system fonts.

WHAT'S INSIDE
index.html            Gallery of all screens
screens/*.dc.html     One file per screen (HTML source, editable)
screens/support.js    Small preview script that makes the screens run
screens/canvas.json   Screen list and layout from the design canvas
